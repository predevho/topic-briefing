### GitHub 프로필의 공개 이메일 — **미해결, 계정 설정이다**

리포지토리와 별개로, **GitHub 프로필에 Gmail이 공개 이메일로 설정돼 있다.**

```bash
$ gh api user --jq .email
<개인 Gmail 주소>
```

**프로필은 리포지토리 공개 여부와 무관하게 이미 공개다.** 커밋을 정리해도
이쪽이 남아 있으면 의미가 줄어든다. 계정 설정이라 리포지토리에서는 고칠
수 없고, 웹에서 직접 바꿔야 한다.

- <https://github.com/settings/profile> → **Public email**을 비우거나
  noreply 주소로 바꾼다
- <https://github.com/settings/emails> → **Keep my email addresses private**를
  켠다. 이걸 켜면 웹 UI에서 하는 커밋도 noreply로 기록된다

## 2. 판단해서 결정한 것 (2026-11-13)

### `config/interests.md` — 개인 프로필 49줄

직업("백엔드 개발자"), 관심 분야, **이미 충분히 아는 주제**, 지루하게
느끼는 주제가 적혀 있다. 민감 정보는 아니지만 읽는 취향이 드러난다.

**결정: 그대로 둔다.** 전문을 다시 읽어 보니 개인 신상이 아니라 **편집 방침
문서**다. 드러나는 것은 "백엔드 개발자", "Docker 기초·REST 입문은 이미 안다",
"프런트엔드 프레임워크 세부 비교에 관심 없다" 정도이고 공개 이력서보다 덜
말한다. 반면 이 파일은 선별 품질의 핵심이라, `.gitignore`에 넣고 빈약한 예시만
커밋하면 **리포지토리를 받은 사람이 점수를 재현할 수 없고 나중에 나도 "왜 이
점수가 나왔나"를 설명할 수 없다.**

## 점검 방법

내용 검사는 이렇게 다시 돌린다.

```bash
git ls-files -z | xargs -0 grep -nE \
  '/Users/|/private/tmp/claude-|[a-z0-9]{15,}\.supabase\.co|sb_secret_[A-Za-z0-9]|sk-ant-[A-Za-z0-9]|eyJ[A-Za-z0-9_-]{20,}'
```

**아무것도 나오지 않아야 한다.** `sb_secret_sentinel_...`만 나오면 정상이다
(가짜 키).

커밋 메타데이터는 따로 본다.

```bash
git log --all --format="%ae %an" | sort -u
```
